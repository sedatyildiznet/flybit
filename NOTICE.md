## MaleCNS v1.0

The neural wiring data used by the `flybrain` core is the Drosophila MaleCNS v1.0 connectome produced by FlyEM / HHMI Janelia and collaborators.

Data source:

https://male-cns.janelia.org

The connectome data is not stored in this Git repository. It is downloaded separately by the neural core and remains subject to the MaleCNS data attribution/license terms, including CC BY 4.0 where applicable.

## Scientific scope

Flybit uses measured connectome topology, but the software neural dynamics are a computational model and must not be described as a complete biological brain emulation.
